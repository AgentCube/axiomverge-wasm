# Axiom Verge WASM

A web port of [Axiom Verge]([https://steampowered.com](https://store.steampowered.com/app/332200/Axiom_Verge/)).

**Play:** https://agentcube.github.io/axiomverge-wasm

![Axiom Verge WASM gameplay](homescreen.png)

## Controls

### In-Game Controls

| Action              | Key                   |
| ------------------- | --------------------- |
| Movement            | Arrow Keys            |
| Shoot               | `F`                   |
| Jump                | `Spacebar`            |
| Hold Position       | `A`                   |
| Open Map            | `Tab`                 |
| Pause Menu          | `Enter`               |
| Weapon Quick Select | Number Keys (`1`–`0`) |

### Menu Controls

| Action              | Key                           |
| ------------------- | ----------------------------- |
| Navigate Options    | Arrow Keys                    |
| Confirm / Select    | `Enter` or `Spacebar`         |
| Cancel / Back       | `Q`                           |
| Switch Menu Screens | `Tab`, `Page Up`, `Page Down` |

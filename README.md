# Axiom Verge wasm

Port of [Axiom Verge](https://steampowered.com).

https://agentcube.github.io/axiomverge-wasm

## Controls Layout

### In-Game Controls
* **Movement (Up / Down / Left / Right):** Arrow Keys
* **Shoot:** `F`
* **Jump:** `Spacebar`
* **Hold Position (Aim Lock):** `A` *(locks Trace in place to aim diagonally/vertically)*
* **Laser Drill:** `D`
* **Address Disruptor (Glitch Ray):** `S`
* **Grapple Hook:** `Q`
* **Drone Launcher:** `W`
* **Address Bomb:** `E`
* **Open Map / Inventory:** `Tab`
* **Pause Menu:** `Enter`
* **Weapon Quick Select:** Number keys (`1`–`0`)

### Menu Controls
* **Navigate Options:** Arrow Keys (Up / Down / Left / Right)
* **Confirm / Select:** `Enter` or `Spacebar`
* **Cancel / Back / Exit Menu:** `Q` *(bound to the Grapple / Cancel action)*
* **Switch Menu Screens (Map / Log / Weapons):** `Tab` or `Page Up` / `Page Down`
